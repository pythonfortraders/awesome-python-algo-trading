## 📈 Backtesting Engines

> Simulate, validate, and iterate on trading strategies.

- [bt](https://pmorissette.github.io/bt/) - Flexible backtesting for Python
- [Backtesting.py](https://github.com/kernc/backtesting.py) - Test trading strategies in Python with interactive charts and parameter optimization
- [vectorbt](https://github.com/polakowo/vectorbt) - Fast vectorized backtesting
- [Backtrader](https://github.com/mementum/backtrader) - Popular event-driven framework
- [OpenBacktesting](https://github.com/lucidcog/openbacktesting) - Single-asset historical backtesting with pandas statistics, indicators, and parameter optimization
- [QuantConnect Lean](https://github.com/QuantConnect/Lean) - Production-grade engine
- [fastquant](https://github.com/enzoampil/fastquant) - Backtest strategies in one line
- [Zipline Reloaded](https://github.com/stefan-jansen/zipline-reloaded) - Maintained fork of Quantopian's backtesting engine
- [finmarketpy](https://github.com/cuemacro/finmarketpy) - Backtesting with market analysis
- [TradingView](https://www.tradingview.com/) - Cloud-based backtesting platform

> Trade automation libraries and broker APIs.

- [ib_async](https://github.com/ib-api-reloaded/ib_async) - Interactive Brokers Python API; successor to ib_insync
- [Alpaca-Py](https://github.com/alpacahq/alpaca-py) - Commission-free stock trading
- [ccxt](https://github.com/ccxt/ccxt) - Crypto exchange market data and trading APIs
- [Binance API Python](https://github.com/sammchardy/python-binance) - Binance exchange API
- [IBKR Native API](https://www.interactivebrokers.com/campus/ibkr-api-page/) - Official Interactive Brokers trading and market data APIs
- [Coinbase Advanced Trade](https://github.com/coinbase/coinbase-advanced-py) - Official Python SDK for Coinbase Advanced Trade
- [Kraken API](https://github.com/veox/python3-krakenex) - Kraken exchange API
- [Oanda API](https://github.com/oanda/v20-python) - Forex and CFD trading
- [TickerAll](https://tickerall.com) - Hosted MetaTrader 5 & MT4 broker API with a Python SDK (`pip install tickerall`) — place trades and stream live ticks with no local terminal. Free on demo accounts.
